# React portfolio

This directory contains the Windows XP-inspired React site. From here, run `npm ci` then `npm run dev`. Use `npm run build` and `npm run preview` to test the static build. Shared assets and résumé are copied from the repository root before dev/build; edit the root copies.

The GitHub Pages workflow builds this app automatically. See the root `README.md` for deployment, metadata and future static-generation notes.
